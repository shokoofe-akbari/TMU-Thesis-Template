# فایل Word چهارصفحه‌ای تحویل رساله ریاضی

فایل `Math-Submission-4-Pages-PhD.docx` همراه Word مورد نیاز برای رساله‌های ریاضی نوشته‌شده با LaTeX است و دقیقاً چهار صفحه دارد:

1. عنوان فارسی؛
2. چکیده و واژگان کلیدی فارسی؛
3. چکیده و کلیدواژه‌های انگلیسی؛
4. عنوان انگلیسی.

عبارت‌های داخل کروشه با اطلاعات واقعی جایگزین می‌شوند. تاریخ به‌صورت خودکار درج نمی‌شود و باید ماه و سال دفاع نوشته شود. پس از تکمیل، تعداد صفحات و یکسان‌بودن عنوان، چکیده و کلیدواژه‌ها با PDF نهایی و سامانه پارسه کنترل شود.

راهنمای کامل در `docs/official-format-1403.md` بسته قرار دارد.
