# راهنمای رفع اشکال

## خطای Font not found

پوشه `Fonts` باید در کنار فایل اصلی باقی بماند و نام فایل‌های آن تغییر نکند. قالب فونت‌ها را از مسیر محلی می‌خواند و به نصب سراسری آن‌ها در ویندوز وابسته نیست.

## خطا هنگام استفاده از pdfLaTeX

این قالب با `XeLaTeX` ساخته می‌شود. استفاده از `pdfLaTeX` یا انتخاب Compiler نادرست در Overleaf باعث خطا در `xepersian` و فونت‌ها می‌شود.

## پیدا نشدن Biber

در حالت منابع `bib`، فرمان `biber` باید نصب و در `PATH` قابل دسترس باشد. نصب کامل TeX Live معمولاً این ابزار را فراهم می‌کند. راه جایگزین، انتخاب موقت حالت `manual` و استفاده از `References.tex` است.

## علامت سؤال به‌جای شماره ارجاع

پردازش یک‌مرحله‌ای برای ارجاع‌های متقاطع کافی نیست. اجرای `build.ps1` یا `latexmk` تعداد مراحل لازم را خودکار انجام می‌دهد.

## هشدار Citation undefined

کلید داخل `\cite{...}` با کلید موجود در `References.bib` یا `\bibitem` مقایسه شود. تفاوت حروف بزرگ و کوچک نیز مؤثر است.

## خطای PowerShell Execution Policy

بدون تغییر دائمی تنظیمات سیستم، فرمان زیر قابل استفاده است:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

## باقی‌ماندن خطا پس از اصلاح فایل

فایل‌های ساخت قدیمی ممکن است با ارجاع‌ها یا شیوه منابع جدید ناسازگار باشند. از داخل پوشه قالب اجرا می‌شود:

```powershell
latexmk -C
.\build.ps1
```

این فرمان فقط خروجی‌های قابل‌بازسازی LaTeX را پاک می‌کند؛ فایل‌های `tex`، فونت‌ها، شکل‌ها و منابع حذف نمی‌شوند.

## Overfull یا Underfull

اسکریپت ساخت این هشدارها را خطای کنترل کیفیت در نظر می‌گیرد. جدول‌های عریض، فرمول‌های طولانی، نشانی‌های اینترنتی و شکل‌های بزرگ از علت‌های رایج‌اند. عرض جدول یا شکل باید با عرض متن سازگار شود و شکست مناسب برای عبارت‌های طولانی در نظر گرفته شود.
